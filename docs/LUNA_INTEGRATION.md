# 集成维护约定

当前项目已经集成双/四人基础版规则、存档和前端。本文件是后续维护约定，不再是待外接后端的任务单。

- 后端规则唯一来源是 `backend/engine.py`；训练环境和网页共用它。
- 玩家 HTTP 视图必须在服务端脱敏，不能把完整 GameState 发给浏览器。
- 网页只提交签名 action_id 和 expected_revision，不提交自行构造的规则动作。
- 所有额外行动与防御选择由后端提供阶段和决策者；前端不假定固定交替。
- 四人的单位所有者与队伍必须分开。地图按队伍着色，手牌按具体席位隔离。
- 保留 JSON 快照与回放版本；规则语义改变后不得混用旧训练标签。
- 修改后运行相关 Python 测试、前端契约检查和构建；涉及真实流程时补做浏览器验证。

接口见 `backend-contract.md` 和 `training-api.md`；现状与验证证据见 `VALIDATION.md`。
